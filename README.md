# HNBUMU Medical Department — Vite + React

Modern multi-section institutional website concept built with Vite + React.

## Run
npm install
npm run dev

## Build
npm run build

## Vercel
Import this GitHub repository into Vercel. Framework preset: Vite.
Build command: npm run build
Output directory: dist

faculty information, contact details and statements before public deployment.
